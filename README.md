Project Overview
This project implements a multi-department Local Area Network (LAN) simulation using Cisco Packet Tracer. Based on academic research concepts, the network design demonstrates VLAN segmentation, inter-VLAN routing, and hierarchical network architecture for a university faculty environment.

Technical Implementation
Devices: 2 switches, 1 router, 8 PCs, 1 DNS server

VLANs: 5 VLANs separating Computer Science, Engineering, Business, and Biotechnology departments

Routing: Router-on-a-stick inter-VLAN routing configuration

Services: DNS server with hostname resolution across all VLANs

Key Features
VLAN-based departmental network segmentation

Inter-VLAN routing for controlled cross-department communication

Structured IP addressing scheme (192.168.x.0/24 subnets)

DNS service implementation for name resolution

Comprehensive connectivity testing and validation
